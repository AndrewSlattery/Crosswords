# Keynesian Cryptics - Letter Selection

This document outlines the indicators used to select specific letters from fodder strings in cryptic crosswords.

## Structures

Here, `!ind` denotes the indicator word or phrase, and `!str` denotes the fodder string.

Valid constructions include but are not limited to:

| Construction | Example |
|--------------|---------|
| `!str's !ind` | Land's End = D |
| `!str at !ind` | peace at last = E |
| `!ind of !str` | Origin of Species = S |
| `!ind from !str` | back from war = R |
| `!ind in !str` | ultimate in fashion = N |
| `!ind for !str` | centre for excellence = LL |
| `!ind on !str` | opening on Wednesday = W |

Modifiers and verbs can select letters with mere apposition:

| Construction | Example |
|--------------|---------|
| `!str !ind` | could initially = C |
| `!ind !str` | evacuated town = TN |

Plural indicators can select parts of multiple strings:

| Construction | Example |
|--------------|---------|
| `!str !str ...` | heads of the schools = T S |
| `!str and !str` | Mum and Dad's faces = M + D |
